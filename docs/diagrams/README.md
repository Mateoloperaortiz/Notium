# Diagrama de arquitectura

- `notium-arquitectura.drawio`: archivo editable. Se abre en [draw.io](https://app.diagrams.net)
  con **Archivo → Abrir desde → Dispositivo**.
- `notium-arquitectura.png`: exportación del diagrama, la misma imagen que aparece en la wiki.

El diagrama sigue la plantilla vista en clase y muestra las carpetas y archivos que existen en
`src/`. Si un cambio agrega, mueve o elimina archivos, el equipo actualiza el `.drawio` a mano y
vuelve a exportar el PNG con **Archivo → Exportar como → PNG**.
