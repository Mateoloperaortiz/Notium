# Diagramas

Cada diagrama tiene su archivo editable de draw.io y su exportación en PNG, que es la misma imagen
que aparece en la wiki. El `.drawio` se abre en [draw.io](https://app.diagrams.net) con
**Archivo → Abrir desde → Dispositivo**.

- `notium-arquitectura.drawio` y `notium-arquitectura.png`: diagrama de arquitectura. Sigue la
  plantilla vista en clase y muestra las carpetas y archivos que existen en `src/`.
- `notium-clases.drawio` y `notium-clases.png`: diagrama de clases. Muestra las interfaces de
  `src/interfaces/`, sus enums y las relaciones por ID entre ellas.

Si un cambio agrega, mueve o elimina archivos, o cambia una interfaz, el equipo actualiza el
`.drawio` a mano y vuelve a exportar el PNG con **Archivo → Exportar como → PNG**.
